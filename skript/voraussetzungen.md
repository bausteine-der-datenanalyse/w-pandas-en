The following modules should already have been completed:

- w-Python-en
- w-NumPy-en

This module uses the following libraries:

- NumPy
- Pandas
- Matplotlib
- zoneinfo (optional)

The module works with the following datasets:

- Tooth growth in guinea pigs [CSV file](https://github.com/vincentarelbundock/Rdatasets/blob/master/csv/datasets/ToothGrowth.csv)
- Vehicle data from _Motor Trend_ magazine [GitHub](https://gist.github.com/seankross/a412dfbd88b3db70b74b)
- Penguin measurements from Palmer Station [GitHub](https://github.com/allisonhorst/palmerpenguins?tab=readme-ov-file#meet-the-palmer-penguins)
- Microsoft stock price data [Kaggle](https://www.kaggle.com/datasets/vijayvvenkitesh/microsoft-stock-time-series-analysis)
